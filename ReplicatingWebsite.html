For a school assignment, I was challenged to recreate two pages in 10 weeks of an existing website using only vanilla HTML, CSS, and JavaScript. I chose to recreate the World of Warcraft website, specifically the Dragonflight page and the homepage. The goal was to improve my skills in responsive web design, accessibility, and JavaScript.

Development Progress

Initial Design

I started by analyzing the original website to understand its structure and visual style. Based on this, I created a semantically correct HTML structure. For the visual styling, I used CSS and applied custom properties to maintain consistent colors throughout the project.

Development

The development phase focused heavily on responsiveness and accessibility. I used a mobile-first approach to ensure the website worked well on various devices. Additionally, I implemented a micro-interaction on the Dragonflight page using JavaScript.

Results

  • Responsive and accessible design
  • Fully functional Homepage and DLC page
  • Visually appealing and user-friendly interface
  • Well-structured, semantic HTML

Reflections

I am particularly proud of my improved understanding of responsive design and my ability to implement JavaScript for interactive elements. This project taught me a lot about semantic HTML and design consistency. In future projects, I aim to refine my CSS layouts even further.
